# 📱 Used Phone Price Analysis Dashboard (Excel)

## Project Overview
This project analyzes a used smartphone dataset using Microsoft Excel. The objective is to identify the key factors that influence selling prices, including brand, device condition, storage capacity, RAM, and phone age. An interactive dashboard with PivotTables, PivotCharts, KPI cards, and Slicers was created to support data-driven insights.

---

## Business Questions
- Which brand has the highest average selling price?
- Which condition has the highest resale value?
- Does RAM affect selling price?
- Does storage affect selling price?
- Does phone age affect selling price?

---

## Dataset
The dataset contains **1,000 used smartphone records** with the following attributes:

- Phone ID
- Brand
- Model
- Selling Price (USD)
- Original Price (USD)
- Phone Age (Years)
- RAM (GB)
- Storage (GB)
- Condition
- Battery Health (%)
- Seller Type
- Warranty
- City
